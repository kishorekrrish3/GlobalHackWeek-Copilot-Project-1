# Portfolio Website Concept

**A responsive, single-page portfolio template for a product designer and front-end developer persona.**

This project is a static HTML/CSS/JavaScript portfolio concept created as part of a GitHub Copilot / Global Hack Week exercise. It demonstrates a polished editorial layout with a hero, selected work, about section, contact area, and a light/dark theme toggle.

> **Template note:** The current page uses the sample persona “Alex Morgan” and placeholder portfolio content. Replace the name, location, project descriptions, links, and contact details before adapting it for a real person or publishing it as your own portfolio.

## Features

- Responsive single-page layout
- Project/work showcase
- About and contact sections
- Light/dark theme toggle
- CSS design tokens for consistent spacing, colors, and typography
- Semantic HTML and a skip-to-content link
- Vanilla JavaScript interactions

## Run locally

No build tooling is required.

```bash
git clone https://github.com/kishorekrrish3/GlobalHackWeek-Copilot-Project-1.git
cd GlobalHackWeek-Copilot-Project-1
```

Open `index.html` in a browser or use a local static web server.

## Project files

- `index.html` — page structure and content
- `tokens.css` — design tokens
- `styles.css` — layout and responsive styles
- `script.js` — interactive behavior
